# Project instructions

- Function over aesthetics: prioritize clear, usable workflows.
- Build phone-first and keep runtime operation offline on the local network.
- Preserve the agreed role permissions and card, payment, visitor and retention workflows.
- Keep hardware simulation clearly identified. Never claim real controller confirmation.
- Inspect existing code before modifying it. Preserve local work.
- Components use the typed service boundary; enforce permissions in services as well as UI.
- Do not publish, deploy, push or create a remote without an explicit request.
- Always clean up codes and files not in use and leave the project clean.
